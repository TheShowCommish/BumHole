One-time setup

This app stores everything in your own Supabase database so all 12 of you share the same board from any device. It takes about five minutes to wire up:

  1. Create a free account at supabase.com and start a new project.
  2. In your project, open SQL Editor → New query, paste in the whole schema.sql file that came with this app, and hit Run. That builds the tables and loads your 2025 season.
  3. Go to Project Settings → API and copy the Project URL and the publishable (client-safe) key.
  4. Open this HTML file in a text editor. Near the top of the <script> block, paste them into SUPABASE_URL and SUPABASE_ANON_KEY.
  5. Save, reload, and you're live. Host the file anywhere static (Netlify, Vercel, GitHub Pages, Cloudflare Pages) and share that URL with the league.

Worth knowing before you make the page public: the publishable key and the odds-API key both sit in the page source where anyone can read them, and the database policies in schema.sql let anyone with the URL read and write. That's fine for a private link among friends. The bottom of schema.sql spells out how to tighten it if you ever want the page truly public.
